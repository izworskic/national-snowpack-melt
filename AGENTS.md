# Agent boundary

Work only inside this repository's stated ownership scope.

Do not copy implementation from sibling tool repositories. Shared location/freshness helpers belong in `izworskic/national-outdoor-core`. Cross-tool behavior must use explicit versioned package or HTTP contracts.

Preserve existing public canonical URLs unless a migration issue explicitly authorizes a URL change.


## Experience OS v1 adoption for substantial visitor-facing changes
For significant interactive Lake-Effect Snow or other owned-tool UX work, apply the research-first Experience OS v1 documentation at
https://github.com/izworskic/chrisizworski-com/tree/main/design-systems/experience-os-v1
(read AGENTS.md, README.md, inspiration/pattern/anti-pattern/technology/QA documents).
Treat it as visitor-experience governance, not an authorization to copy templates or move product ownership.
Document alternatives, source evidence, fallbacks, browser QA and the release scorecard in this repository.
Keep canonical/ads/data truth/ownership and local AGENTS rules authoritative. Do not merge with red or unmeasured hard gates.
